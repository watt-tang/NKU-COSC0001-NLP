# 自然语言处理 Lab 1 实验报告

## 不同文本表示方法在 NYT 新闻分类任务中的比较

---

## 1. 实验目的与任务描述

本实验围绕文本分类中的不同 Representation（文本表征）方法展开，目标是在统一的数据划分和评价指标下，比较传统稀疏词袋表示、静态词向量表示以及预训练语言模型在新闻分类任务中的实际效果。

实验以 New York Times（NYT）新闻数据集作为主要分类数据集，类别包括 `sports`、`politics` 和 `business`。按照作业要求，实验共完成三个部分：

- **Task 1：Bag of Words（词袋模型）**
  - Binary Bag of Words（二值词袋）
  - Word Frequency（词频词袋）
  - 两种表示均使用 Logistic Regression（逻辑回归）完成分类。
- **Task 2：Word Embedding（词嵌入）**
  - Pre-trained GloVe 100d
  - Word2Vec trained on AG News
  - Word2Vec trained on NYT
  - 三种方法均将单词表示为 100 维向量，再通过 Mean Pooling（平均池化）得到文档向量，最后使用 Logistic Regression 分类。
- **Task 3：Pre-trained Neural Model（预训练神经语言模型）**
  - 使用 `google-bert/bert-base-uncased`
  - `max_length = 64`
  - Fine-tuning（微调）3 epochs
  - 在 NYT Test Set 上报告 Accuracy 和 Macro-F1。

本实验主要关注以下问题：

1. 简单的词袋表示与分布式词向量表示在新闻主题分类中有何差异；
2. Binary BoW 与 Word Frequency 是否存在明显性能差异；
3. Word2Vec 的训练语料是否会影响下游分类效果；
4. GloVe 的大规模预训练和低 OOV 是否必然带来更高的分类性能；
5. BERT Fine-tuning 在当前长新闻、短截断长度设置下的表现如何；
6. 不同文本表示方法的错误模式是否具有共同规律。

为了避免只关注总体 Accuracy，本实验同时使用 Macro-F1，并结合 Classification Report（分类报告）、Confusion Matrix（混淆矩阵）和 Bad Case Analysis（错例分析）对结果进行讨论。

## 2. 数据集与实验设置

### 2.1 NYT 数据集

NYT 数据集包含 `text` 和 `label` 两列，其中 `text` 为新闻正文，`label` 为新闻类别。数据清洗后共有 **11,519** 条有效样本，类别分布如下。

| 类别           |           样本数 |           占比 |
| -------------- | ---------------: | -------------: |
| sports         |            8,639 |       约 75.0% |
| politics       |            1,451 |       约 12.6% |
| business       |            1,429 |       约 12.4% |
| **总计** | **11,519** | **100%** |

可以看到数据存在明显的 Class Imbalance（类别不均衡）：`sports` 占全部样本约四分之三，而 `politics` 和 `business` 的样本数量明显较少。这意味着如果模型主要把多数类识别正确，即使少数类效果一般，也可能取得较高的总体 Accuracy。因此本实验除 Accuracy 外，还重点报告 Macro-F1。

### 2.2 AG News 数据集

AG News 数据集在本实验中不直接参与 NYT 分类，只用于 Task 2 中训练外部 Word2Vec。实验使用其中 **90,000** 条文本训练 100 维 Word2Vec，并将得到的词向量用于 NYT 文档表示。

这样可以与直接在 NYT Training Set 上训练得到的 Word2Vec 进行比较，从而观察 Domain Matching（领域匹配）对词向量下游性能的影响。

### 2.3 数据划分

所有正式实验使用完全相同的 NYT 数据划分：

| 数据集         | 比例 | 样本数 |
| -------------- | ---: | -----: |
| Training Set   |  80% |  9,215 |
| Validation Set |  10% |  1,152 |
| Test Set       |  10% |  1,152 |

划分时统一设置：

```python
random_state = 42
stratify = y
```

其中 `stratify` 保证三个数据子集中的类别比例与原始数据基本一致。

统一数据划分非常重要。如果不同表示方法使用不同 Test Set，那么最终 Accuracy 和 Macro-F1 的差异可能来自测试样本本身，而不是 Representation 的优劣。通过固定随机种子和相同的分层划分，本实验尽量保证各方法之间具有可比性。

### 2.4 评价指标

#### Accuracy

Accuracy（准确率）表示预测正确的样本占全部测试样本的比例：

$$
Accuracy=\frac{N_{\text{correct}}}{N_{\text{total}}}
$$

Accuracy 能够直接反映总体分类正确率，但在类别不均衡数据上可能受到多数类影响。

#### Macro-F1

对于每个类别分别计算 Precision（精确率）、Recall（召回率）和 F1-score：

$$
Precision=\frac{TP}{TP+FP}
$$

$$
Recall=\frac{TP}{TP+FN}
$$

$$
F1=\frac{2\times Precision\times Recall}{Precision+Recall}
$$

之后对所有类别的 F1 取平均：

$$
Macro\text{-}F1=\frac{1}{C}\sum_{c=1}^{C}F1_c
$$

其中 $C$ 表示类别数量。本实验中 $C=3$。

由于 `sports` 占样本约 75%，Macro-F1 比单独 Accuracy 更能反映模型在 `business` 和 `politics` 两个少数类别上的真实分类能力。

## 3. 方法与实现

### 3.1 Task 1：Bag of Words

Task 1 比较 Binary Bag of Words 和 Word Frequency 两种词袋表示方法，并统一使用 Logistic Regression 分类。

#### Binary Bag of Words

首先只利用 Training Set 建立 Vocabulary（词表）。假设词表大小为 $|V|$，则每篇文档表示为一个 $|V|$ 维向量。

对于词表中的第 $i$ 个词：

$$
x_i=
\begin{cases}
1, & \text{该词出现在文档中}\\
0, & \text{该词未出现在文档中}
\end{cases}
$$

例如词表为：

```text
[team, game, market, president]
```

文档为：

```text
team team game
```

则 Binary BoW 表示为：

```text
[1, 1, 0, 0]
```

即只关心某个词是否出现，而不关心其出现次数。

代码使用：

```python
CountVectorizer(binary=True)
```

建立词袋特征。

#### Word Frequency

Word Frequency 使用与 Binary BoW 相同的 Vocabulary，但保留每个词在当前文档中的实际出现次数：

$$
x=(c_1,c_2,\ldots,c_{|V|})
$$

例如：

```text
apple apple banana
```

得到：

```text
apple  = 2
banana = 1
```

代码使用：

```python
CountVectorizer(binary=False)
```

实现。

两种方法最后均产生大小为 **60,980** 的稀疏词表特征，并输入 Logistic Regression。

为了避免 Data Leakage（数据泄漏），Vectorizer 只在 Training Set 上执行 `fit`，Validation Set 和 Test Set 只执行 `transform`。

---

### 3.2 Task 2：Word2Vec 与 GloVe

Task 2 使用静态 Word Embedding（词嵌入）表示文本，所有词向量维度统一为 **100**。

实验包括：

1. Pre-trained GloVe 100d；
2. AG News Word2Vec 100d；
3. NYT Word2Vec 100d。

与高维稀疏 BoW 不同，Word2Vec 和 GloVe 将每个单词表示为低维稠密向量。

对于一篇包含 $n$ 个有效词的新闻，设词向量分别为：

$$
e(w_1),e(w_2),\ldots,e(w_n)
$$

则文档向量采用 Mean Pooling：

$$
e(d)=\frac{1}{n}\sum_{i=1}^{n}e(w_i)
$$

最终每篇新闻被表示为一个 100 维向量，并使用 Logistic Regression 分类。

#### NYT Word2Vec

NYT Word2Vec 只使用 NYT **Training Set** 训练，而没有使用 Validation Set 和 Test Set，从而避免测试文本参与 Representation 学习。

主要参数如下：

```python
vector_size = 100
window = 5
min_count = 2
epochs = 10
sg = 0
```

其中：

- `vector_size=100`：词向量维度为 100；
- `window=5`：上下文窗口为 5；
- `min_count=2`：忽略只出现一次的低频词；
- `sg=0`：使用 CBOW；
- `epochs=10`：训练 10 轮。

NYT Training Set 约包含 **5,973,837 tokens**，最终 Vocabulary Size 为 **41,838**。

#### AG News Word2Vec

AG Word2Vec 使用 90,000 条 AG News 文本训练，保持与 NYT Word2Vec 相同的 100 维设置和主要超参数。

AG News 语料约包含 **3,446,946 tokens**，最终 Vocabulary Size 为 **35,660**。

这样可以在模型结构和向量维度相同的前提下，将性能差异主要归因于训练语料不同。

#### Pre-trained GloVe

第三种方法使用公开的 `glove.6B.100d` 预训练词向量。

对于每篇 NYT 新闻：

1. 对文本进行分词；
2. 查询每个有效单词的 GloVe 100 维向量；
3. 忽略不存在于 GloVe Vocabulary 中的词；
4. 对剩余词向量取平均；
5. 使用得到的 100 维文档向量训练 Logistic Regression。

Task 2 同时统计 OOV（Out-of-Vocabulary，未登录词）比例，用于分析不同词向量模型对 NYT 文本的覆盖情况。

### 3.3 Task 3：BERT-base Fine-tuning

Task 3 按照作业要求使用：

```text
Pre-trained Model : google-bert/bert-base-uncased
Maximum Length    : 64
Epochs            : 3
```

与 Task 1 和 Task 2 不同，Task 3 不再将 BERT 作为冻结的特征提取器，而是执行真正的端到端 Fine-tuning（微调）。

#### Tokenization

使用 `BertTokenizer` 对文本进行编码，并设置：

```python
max_length = 64
padding = "max_length"
truncation = True
```

长度超过 64 tokens 的新闻会被截断，不足 64 的会进行 Padding（填充）。

#### 分类模型

使用：

```python
BertForSequenceClassification
```

构建三分类模型：

```text
BERT-base-uncased
        ↓
Pooled Representation
        ↓
Classification Head
        ↓
business / politics / sports
```

分类层将 BERT 的句级表示映射到三个类别。其预测可以写为：

$$
p(y\mid x)=\operatorname{softmax}(Wh+b)
$$

其中 $h$ 为 BERT 输出的句级表示，$W$ 和 $b$ 为分类层参数。

训练采用 Cross Entropy Loss（交叉熵损失）：

$$
L=-\sum_{c=1}^{C}y_c\log p_c
$$

Fine-tuning 过程中 BERT Encoder 和 Classification Head 都参与反向传播，模型参数会根据 NYT 分类任务进行更新。

#### 训练配置

正式实验使用：

```text
Batch Size       : 8
Learning Rate    : 2e-5
Weight Decay     : 0.01
Warmup Ratio     : 0.10
Epochs           : 3
Max Length       : 64
Optimizer        : AdamW
Gradient Clipping: 1.0
```

按照作业要求，模型完整训练 3 epochs，不使用 Early Stopping（提前停止）。每个 epoch 后在 Validation Set 上计算 Accuracy 和 Macro-F1，并根据 Validation Macro-F1 保存最佳 Checkpoint（检查点）。

最终在完成 3 epochs 后，重新加载 Validation Macro-F1 最优的模型，并且只在此时对 Test Set 进行最终评价。

这种方式避免直接根据 Test Set 指标选择模型，使 Test Set 仍然只承担最终泛化性能评估的作用。

## 5. 实验结果分析

### 5.1 Bag of Words 与新闻主题分类的高度匹配

本实验中 Binary BoW 和 Frequency BoW 分别取得 **99.05%** 和 **98.96%** 的 Accuracy，优于其他表示方法。

该结果首先与任务本身的性质有关。本实验属于 Topic Classification（主题分类），三个类别之间具有大量高度区分性的关键词。例如：

```text
sports:
team / game / player / coach / football / league

politics:
president / senate / congress / government / administration

business:
company / market / stock / bank / billion / economic
```

对于这种任务，模型并不一定需要理解复杂语法，只要能够识别文章中是否出现了一组强类别词汇，就已经可以做出相当准确的判断。

BoW 的优势恰好在于，它为每个词保留独立维度。例如 `football` 不会被其他词平均掉，而会形成一个独立特征。Logistic Regression 可以直接学习：

```text
football  → sports
senate    → politics
market    → business
```

等强判别关系。

Binary BoW 又进一步忽略精确词频，只记录出现与否。对于新闻主题分类来说，一个关键词出现 10 次并不意味着它提供了出现 1 次时 10 倍的类别信息。因此 Binary BoW 在一定程度上可以减弱文档长度和重复表达的影响。

但是 Binary 与 Frequency 的差距仅为：

```text
Accuracy : 0.09 percentage points
Macro-F1 : 0.22 percentage points
```

因此最合理的结论不是“Binary 一定优于 Frequency”，而是：

> 当前 NYT 主题分类任务对关键词出现信息高度敏感，而精确词频所增加的信息有限，两种 BoW 方法均能取得很强结果。

这也说明，模型结构是否先进并不能脱离具体任务评价。简单表示如果与任务判别特征高度匹配，完全可能超过更加复杂的语义模型。

---

### 5.2 Word2Vec 的语义优势与平均池化的信息损失

Word2Vec 相比 BoW 能学习词语之间的语义关系。例如：

```text
company ≈ corporation ≈ firm
```

在 BoW 中它们是完全独立的维度，而在 Word2Vec 向量空间中可以具有较近的位置。

这种 Distributed Representation（分布式表示）具有良好的语义泛化能力，但是本实验需要进一步将一篇文章中的所有词向量平均，得到一个固定的 100 维文档向量。

这带来了明显的信息压缩：

```text
60,980 维稀疏 BoW
        ↓
100 维稠密文档向量
```

并且 Mean Pooling 对所有有效词近似等权处理。

假设一篇体育新闻包含：

```text
football / coach / league / player
```

同时还包含大量普通词：

```text
said / year / new / people / one / time
```

平均之后，具有强类别判别能力的词会与大量普通词共同参与文档向量计算，因此关键词信号可能被一定程度稀释。

BoW 则不会把 `football` 和其他词融合，而是完整保留该词对应的独立特征。这解释了为什么在高度依赖关键词的主题分类任务中，高维稀疏 BoW 可以略高于低维 Word2Vec。

此外，简单 Mean Pooling 也会完全丢失词序。例如两句话：

```text
government criticizes company
company criticizes government
```

包含几乎相同的单词，平均词向量也会非常接近，但语义角色不同。

因此 Task 2 的结果并不说明 Word2Vec 本身缺乏语义能力，而是说明：

> Word2Vec 的单词级语义优势经过简单 Mean Pooling 转换成文档表示后，会损失一部分对主题分类非常有价值的词级和结构信息。

---

### 5.3 Word2Vec 训练语料的领域匹配效应

NYT Word2Vec 的正式结果为：

```text
Accuracy = 98.70%
Macro-F1 = 96.72%
```

而 AG Word2Vec 为：

```text
Accuracy = 98.00%
Macro-F1 = 95.17%
```

两组实验采用相同维度和相同主要 Word2Vec 参数，因此训练语料是二者最核心的差别。

NYT Word2Vec 直接从目标新闻语料的 Training Set 中学习词语共现关系，更容易形成与当前分类任务相关的语义空间。例如：

```text
Federal Reserve / bank / market / economy
```

在目标数据中可能经常共同出现在商业类新闻中，而：

```text
senate / congress / president / administration
```

则更容易形成政治类语义聚类。

AG News 虽然同样属于新闻语料，但它的具体主题分布、实体、时间范围和词语上下文与 NYT 并不完全一致。因此同一个单词在两个语料中学习到的向量关系也可能不同。

OOV 进一步体现了这种差异：

```text
NYT Word2Vec Token OOV = 0.71%
AG Word2Vec Token OOV  = 2.63%
```

Unique Word OOV：

```text
NYT Word2Vec = 14.07%
AG Word2Vec  = 31.17%
```

AG Word2Vec 无法覆盖的 NYT 特有词更多，而新闻中的人名、机构名、球队名、政治实体和公司名往往本身就是非常重要的类别线索。

在 NYT Word2Vec 与 AG Word2Vec 的 14 个预测分歧样本中：

```text
NYT correct / AG wrong = 11
AG correct / NYT wrong = 3
```

这进一步说明，**与目标任务更加匹配的训练语料能够带来更适合当前下游任务的词向量。**

---

### 5.4 GloVe 的高覆盖率与下游性能之间的关系

GloVe 在三种静态词向量中具有最低的 OOV：

```text
Token OOV       = 0.20%
Unique Word OOV = 2.98%
```

这说明大规模通用预训练语料带来了非常强的 Vocabulary Coverage（词汇覆盖能力）。

但 GloVe 的 Test Accuracy 为：

```text
98.44%
```

仍略低于 NYT Word2Vec 的：

```text
98.70%
```

Macro-F1 也从 NYT Word2Vec 的 96.72% 略降为 96.33%。

因此：

> 更低的 OOV 并不自动等价于更高的分类性能。

GloVe 的优势是覆盖范围广，而 NYT Word2Vec 的优势是目标领域匹配度高。一个模型能够表示更多单词，并不意味着这些新增覆盖的词都具有较高分类价值。

同时，两种方法最终都要经过 Mean Pooling，将所有词压缩到 100 维文档表示。如果新增覆盖的主要是普通词、背景词或低判别力词，它们并不会显著改善分类。

因此静态词向量的效果应同时考虑：

```text
Vocabulary Coverage
+
Domain Relevance
+
Document Aggregation Method
```

而不能只用 OOV 判断词向量质量。

---

### 5.5 BERT Fine-tuning 的表现与训练动态

BERT-base Fine-tuning 最终得到：

```text
Accuracy = 98.35%
Macro-F1 = 96.27%
```

整体性能很高，但没有超过 BoW 和 NYT Word2Vec。

首先，从训练过程来看，BERT 确实有效学习了分类任务。

Training Loss：

```text
0.2236 → 0.0547 → 0.0188
```

快速下降。

Validation Macro-F1：

```text
0.9402 → 0.9478 → 0.9434
```

在 Epoch 2 达到最高。

第 3 个 epoch 中，Training Loss 继续下降，但 Validation Macro-F1 开始回落，同时 Validation Loss 持续增加。这说明模型已经开始更强地拟合 Training Set，而对 Validation Set 的泛化能力没有同步提升，即出现了轻微的 Overfitting（过拟合）趋势。

因此本实验选择 Epoch 2 的 Checkpoint 作为最终测试模型，而不是简单使用最后一个 epoch。

这一过程体现了 Validation Set 的实际作用：它不是用于汇报最终性能，而是用于训练过程中的模型选择。

---

### 5.6 BERT 未超过 BoW 的原因分析

BERT 是本实验中语义建模能力最强的方法，但最终：

```text
Binary BoW Accuracy = 99.05%
BERT Accuracy       = 98.35%
```

二者相差约 **0.70 个百分点**。

Macro-F1 相差约 **1.37 个百分点**。

这一现象需要结合实验设置理解，而不能直接得出“BERT 不如 BoW”的结论。

#### 原因一：作业规定 `max_length = 64`

NYT 数据是完整新闻文章，文本普遍明显长于 64 tokens。

BERT 在本实验中只能看到：

```text
文章开头前 64 tokens
```

超过部分全部被截断。

而 BoW 和 Word2Vec 在当前实现中能够利用更完整的新闻文本。因此从输入信息量来看，BERT 实际处于明显更强的截断限制下。

对于一篇新闻，如果开头主要介绍事件背景，而真正能够确定主题的实体、政策信息或领域词汇出现在后文，那么 BERT 无法看到这些信息。

#### 原因二：主题分类对关键词非常敏感

BERT 的优势在于上下文建模，而当前任务中的很多样本仅依靠主题词就已经很容易分类。

因此 BERT 所增加的复杂上下文能力未必能在这个任务上带来与计算复杂度相同量级的收益。

反而 BoW 可以利用全文中全部类别关键词，对 Topic Classification 非常有效。

#### 原因三：BERT 与 GloVe 的实际差距极小

GloVe：

```text
Accuracy = 98.44%
Macro-F1 = 96.33%
```

BERT：

```text
Accuracy = 98.35%
Macro-F1 = 96.27%
```

两者差距只有：

```text
Accuracy : 0.09 percentage points
Macro-F1 : 0.06 percentage points
```

该差异非常小。因此不应写成“GloVe 明显优于 BERT”，更合理的结论是：

> 在本次单次实验中，两种方法表现几乎处于同一水平，微小数值差异不足以说明存在稳定的显著性能差异。

同样，NYT Word2Vec 相比 BERT 也只高：

```text
Accuracy : 0.35 percentage points
Macro-F1 : 0.45 percentage points
```

总体来说，后四种方法的结果实际上处于较接近的高性能区间。

---

### 5.7 不同 Representation 的信息保留差异

可以从“每种方法保留了什么信息”来理解最终结果。

| Representation          | 主要保留的信息               | 主要限制                             |
| ----------------------- | ---------------------------- | ------------------------------------ |
| Binary BoW              | 某个词是否出现               | 不考虑词序和上下文                   |
| Frequency BoW           | 词是否出现以及频率           | 不考虑词序和上下文                   |
| Word2Vec + Mean Pooling | 单词级语义关系               | 平均池化稀释关键词，丢失词序         |
| GloVe + Mean Pooling    | 通用语义和较高词汇覆盖       | 领域适配有限，仍存在池化损失         |
| BERT Fine-tuning        | 上下文相关语义并进行任务适配 | `max_length=64` 导致长新闻大量截断 |

因此，不同文本表示方法并不是简单的“旧方法到新方法”的线性升级关系，而是在不同类型的信息之间进行选择和压缩。

当前新闻分类任务最有价值的信息恰好包括大量类别关键词，而 BoW 对这部分信息的保留非常直接，因此取得了最高性能。

---

## 6. 错例分析与讨论

### 6.1 Business 与 Politics 是主要混淆来源

从多组实验的 Classification Report 和 Confusion Matrix 可以观察到一个稳定现象：

> `business` 与 `politics` 的区分难度明显高于 `sports`。

这与新闻内容本身的跨主题特征有关。

商业新闻经常包含：

```text
Federal Reserve
government
policy
administration
official
regulation
```

而政治新闻也经常涉及：

```text
economy
company
insurance
budget
debt
payment
bank
```

因此两类新闻并不存在完全清晰的词汇边界。

BERT Fine-tuning 的混淆矩阵为：

```text
             Predicted
             business  politics  sports

business        131       10        2
politics          2      141        2
sports            1        2      861
```

其中最明显的单一误判方向是：

```text
business → politics : 10
```

说明一部分商业新闻包含大量政治人物、政府机构或政策内容，使模型更倾向于判断为 `politics`。

与此同时：

```text
politics → business : 2
```

明显更少，说明 Fine-tuned BERT 在当前决策边界下对 politics 的 Recall 较高。

这一点从 Classification Report 也可以看到：

```text
politics Recall = 97.24%
business Recall = 91.61%
```

换言之，BERT 很少漏掉真正的 politics，但会把部分跨政策领域的 business 新闻吸收到 politics 类中。

---

### 6.2 代表性 BERT 错例

#### Sports → Politics

一个错例的真实标签为：

```text
sports
```

但文章开头讨论：

```text
dementia
family
medical condition
San Francisco airport
```

体育主题信息在最前面的 64 tokens 中并不突出。由于本实验的 BERT 输入被限制为 64 tokens，模型可能无法看到后文更能体现 sports 类别的内容。

这一案例说明：

> 对长新闻进行较短截断时，文章开头是否包含核心主题信息会直接影响 BERT 分类。

#### Politics → Business

另一个 politics 错例开头涉及：

```text
Boston Marathon bombings
universities
education
research
```

其中 `Boston Marathon` 具有明显的 sports 表面词汇，而新闻实际又讨论恐怖袭击、教育机构和社会事件，主题本身具有明显交叉性。

这类新闻并不具有单一纯粹主题，因此即使使用上下文模型，也可能出现边界判断错误。

#### Business → Sports

一个 business 错例开头出现：

```text
NCAA men's basketball tournament
office pool
brackets
```

这些词具有非常强的 sports 类别信号。

但文章实际核心内容是：

```text
travel credit card
American Express
card perks
```

即商业与信用卡主题。

由于 BERT 只能使用前 64 tokens，文章开头的篮球类比可能被赋予较高影响，而后续真正说明商业主题的信息可能没有完整进入模型。

这个例子非常直观地体现了：

> 对长文档进行短序列截断时，局部开头主题与全文核心主题不一致，会产生额外分类误差。

---

### 6.3 Sports 类别具有最高可分性

BERT Test Set 中共有 864 个 sports 样本，其中：

```text
861 个正确
3 个错误
```

对应 Recall：

```text
99.65%
```

NYT Word2Vec 中 sports 也达到：

```text
863 / 864
```

的正确分类结果。

这说明 sports 类别本身具有非常明显的领域特征。

例如：

```text
team
game
player
football
coach
league
baseball
basketball
```

这些词具有较高的领域专属性，在 politics 和 business 中大量出现的概率较低，因此不同 Representation 都比较容易学习 sports 的分类边界。

与之相比，business 与 politics 共享：

```text
government
policy
economy
official
federal
bank
company
budget
```

等大量词汇，因此两类之间的自然语义重叠更强。

因此模型错误并不全部来自 Representation 本身，**类别的内在可分性也是影响最终性能的重要因素。**

---

### 6.4 类别不均衡对 Accuracy 的影响

本实验数据中：

```text
sports ≈ 75%
```

因此总体 Accuracy 会受到 sports 表现的显著影响。

以 BERT 为例：

```text
Accuracy = 98.35%
Macro-F1 = 96.27%
```

两者相差约：

```text
2.08 percentage points
```

原因在于 sports F1 高达：

```text
99.60%
```

而：

```text
business F1 = 94.58%
politics F1 = 94.63%
```

明显低一些。

Accuracy 中 864 个 sports 样本占据绝大多数，因此 sports 接近满分会显著抬高整体 Accuracy。

Macro-F1 则对三个类别一视同仁，所以更清楚地暴露出模型在 business 和 politics 上的相对困难。

因此本实验不能只看 Accuracy，而需要同时报告 Macro-F1。

---

### 6.5 不同模型错误边界的差异

NYT Word2Vec 混淆矩阵中：

```text
business → politics : 5
politics → business : 8
```

而 BERT 中：

```text
business → politics : 10
politics → business : 2
```

两个模型在 business / politics 边界上出现了明显不同的错误方向。

这说明 Representation 的改变不仅影响“错多少”，也会改变模型对边界样本的判断方式。

Word2Vec 通过平均静态词向量表示全文，可能更容易受到全文商业/政治词汇总体分布的影响。

BERT 则能够进行上下文建模并通过 Fine-tuning 学习任务相关表示，但只输入前 64 tokens。因此它对文章开头中政治人物、政府机构和政策词汇可能更敏感。

这并不能简单理解为某一种错误方式更好，而说明：

> 不同 Representation 关注的信息不同，因此即使最终 Accuracy 接近，也可能形成不同的决策边界和不同的 Bad Case。

---

## 7. 结论

本实验在相同的 NYT 数据划分下，系统比较了 Binary BoW、Frequency BoW、NYT Word2Vec、AG Word2Vec、GloVe 100d 和 BERT-base Fine-tuning 等多种文本表示方法，并统一使用 Accuracy 和 Macro-F1 进行评价。

最终结果如下：

| Representation        |    Test Accuracy |    Test Macro-F1 |
| --------------------- | ---------------: | ---------------: |
| Binary BoW            | **0.9905** | **0.9764** |
| Frequency BoW         |           0.9896 |           0.9742 |
| NYT Word2Vec          |           0.9870 |           0.9672 |
| GloVe 100d            |           0.9844 |           0.9633 |
| BERT-base Fine-tuning |           0.9835 |           0.9627 |
| AG Word2Vec           |           0.9800 |           0.9517 |

首先，Binary BoW 在本实验中获得最高的 Accuracy 和 Macro-F1，说明对于 NYT 这类具有明显主题关键词的新闻分类任务，简单词汇出现特征已经具有很强的判别能力。

Binary BoW 与 Frequency BoW 的结果非常接近，表明精确词频在当前任务中带来的额外收益较小，单词是否出现已经能够提供大量有效信息。

其次，Word2Vec 实验显示训练语料对下游任务具有明显影响。NYT Word2Vec 高于 AG Word2Vec，并且在两者预测分歧的样本中，NYT Word2Vec 正确的数量更多。这说明 Domain Matching 对词向量质量具有重要作用。

GloVe 具有最低的 OOV，但结果仍略低于 NYT Word2Vec，说明 Vocabulary Coverage 不是决定下游性能的唯一因素。训练语料的领域相关性以及文档向量构造方式同样重要。

BERT-base Fine-tuning 达到 98.35% Accuracy 和 96.27% Macro-F1，证明端到端预训练语言模型能够有效适配当前任务。训练过程中 Epoch 2 的 Validation Macro-F1 最高，而 Epoch 3 Training Loss 继续下降但 Validation 指标回落，说明模型后期出现了轻微过拟合。

BERT 没有超过 BoW 和 NYT Word2Vec，一个重要原因是作业规定 `max_length=64`，导致完整 NYT 新闻被大幅截断。相比之下，BoW 和 Word2Vec 可以利用更完整的文档信息。此外，当前任务本身高度依赖主题关键词，也使传统词汇表示具有天然优势。

错例分析进一步表明，`business` 与 `politics` 是主要混淆类别，而 `sports` 的类别边界更加清晰。部分错误来源于新闻本身跨越政治、经济、社会等多个主题，而非单纯由模型能力不足造成。

综合实验结果，本实验得到的核心认识是：

> **文本表示方法不存在脱离任务的绝对优劣。更复杂的模型能够表达更加丰富的语言信息，但这种表示能力只有在输入信息充分、训练方式适合且新增语义信息对具体任务有价值时，才会稳定转化为更高的下游性能。**

对于本实验的新闻主题分类任务，BoW 与关键词判别特征高度匹配，因此取得了最高性能；Word2Vec 和 GloVe 提供了更加紧凑的语义表示，但 Mean Pooling 会损失一部分词级判别信息；BERT 能够进行上下文建模和任务微调，但受到 `max_length=64` 的长文本截断限制。

因此，相比简单地按照模型复杂程度判断优劣，更合理的做法是根据数据规模、文本长度、任务类型、计算资源和目标评价指标选择适合的 Representation。
